Live Java HTTPS test of 12 endpoints; verifies pinned compromised intermediate public keys. PASS means all 12 rejected; FAIL means a verified compromised chain was accepted; INCONCLUSIVE means insufficient evidence.

How each check works

blocked.certs fingerprint inventory

Checks the presence of the 48 expected compromised-intermediate fingerprints; it does not establish runtime TLS behavior.

Official/reference documentation

CheckCerts (CVE-2026-114820)

Runs the original OpenJDK source against the stock JDK default TrustManagerFactory, inspecting accepted issuers for four monitored roots. ROOT_PRESENT indicates one or more roots remain; ROOTS_ABSENT indicates none is reported. This is an effective root-inventory check related to Oracle root-removal remediation for CVE-2026-114820, not a TLS handshake test.

Official/reference documentation

TLS chain test

Uses a delegating Java trust manager to check twelve live certificate chains with pinned compromised intermediate SPKI hashes; PASS indicates all twelve rejected. Not a universal proof of PKIX immunity.
